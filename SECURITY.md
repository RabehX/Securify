# Security Policy

Securify takes security and responsible disclosure seriously. As a root detection and Play Integrity API utility, maintaining integrity and security is paramount.

---

## Supported Versions

Only the latest release receives active security patches.

| Version | Supported | Notes |
| :--- | :--- | :--- |
| `2.0.x` | ✅ Yes | Current development milestone |
| `1.4.x` | ⚠️ Critical only | Security fixes backported on request |
| `< 1.4.0` | ❌ No | End of life |

---

## Reporting a Vulnerability

> [!CAUTION]
> **Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in Securify, please disclose it privately through one of the following channels:

### 1. GitHub Private Vulnerability Reporting (Preferred)
Navigate to the [Securify Security Tab](https://github.com/RabehX/Securify/security/advisories/new) and click **"Report a vulnerability"**. This allows secure coordination and testing before public disclosure.

### 2. Direct Security Contact
If you prefer email, contact the maintainer directly:
- **Email**: `rabehxofficial@gmail.com`
- **Subject Line**: `[SECURITY VULNERABILITY] Securify - <Brief Summary>`

Please include in your report:
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC) code.
- Impact assessment (affected devices, API versions, or threat model).
- Suggested remediation or patch, if available.

---

## Our Security Commitments

1. **Initial Response**: We will acknowledge your report within **48 hours**.
2. **Assessment & Triage**: We will investigate and provide a severity assessment within **5 business days**.
3. **Fix & Release**: We will work on a patch and coordinate a disclosure timeline (typically 30–90 days, depending on severity).
4. **Credit**: We will credit reporters in the release notes and advisory (unless requested to remain anonymous).

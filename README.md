## Features

- Checks for Magisk and KernelSU-related modifications.
- Verifies Play Integrity results through the configured backend.
- Shows device details including ABI, kernel version, fingerprint, and security patch level.
- Uses Material 3 Expressive with dynamic color, theming, and AMOLED-friendly settings.
- Supports a broad set of ABIs and Android-based emulators.
